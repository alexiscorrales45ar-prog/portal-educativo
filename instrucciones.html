👨‍🎓 Flujo: Acceso para Estudiantes

1 Abrir el portal

El estudiante abre el archivo index.html en su navegador (Chrome, Firefox, Safari, Edge)

2 Explorar el sitio

Navega por los menús: Inicio, Arte, Literatura, Convivencia, Eventos

3 Ver contenido de docentes

Cada sección muestra el contenido que los docentes han cargado

4 Dejar comentarios

Completa el formulario de comentarios y haz clic en "Enviar"

✅ El comentario se guarda automáticamente y aparece en la página

👨‍🏫 Flujo: Acceso para Docentes

1 Entrar al Panel Docente

Haz clic en el botón "Panel Docente" en la navegación

2 Iniciar Sesión

Usuario: docente
Contraseña: 123456

3 Rellenar formulario de carga
  • Sección: Elige dónde aparecerá (Arte, Literatura, Convivencia, Eventos)
  • Título: Nombre del contenido
  • Descripción: Explicación breve (máx 500 caracteres)
  • Enlace: URL a recurso (Google Drive, YouTube, PDF, etc)
4 Cargar contenido

Haz clic en "Cargar Contenido"

✅ El contenido aparece inmediatamente en la sección correspondiente
✅ Los estudiantes pueden verlo cuando abren esa página
5 Gestionar contenido

Puedes:
• Ver todo tu contenido por sección
• Hacer clic en "Ver recurso" para abrir enlaces
• Eliminar contenido si es necesario

💾 Dónde se guardan los datos

DATOS
↓
localStorage del navegador
↓
VISIBLES EN: Chrome, Firefox, Safari, Edge (por separado)
⚠️ Importante: Los datos se guardan POR NAVEGADOR. Si abres el portal en:
  • Chrome: Los datos se guardan ahí
  • Firefox: Los datos son diferentes
  • Safari en otro PC: No ve los datos

Para producción real: Se recomienda usar una base de datos SQL con servidor backend.

📝 Ejemplo Práctico Completo

Escenario: Docente de Arte quiere compartir tutorial de pintura

  1. Docente entra a Panel Docente
  2. Login: docente / 123456
  3. Completa formulario:
    Sección: 🎨 Arte Título: Técnicas de Acrílico para Principiantes Descripción: Video tutorial completo (15 min) sobre materiales, mezcla de colores y primeros proyectos Enlace: https://youtu.be/video123
  4. Haz clic en "Cargar Contenido"
  5. ✅ Éxito: El contenido aparece en la página Arte
  6. Los estudiantes ven el contenido cuando abren "Arte"
  7. Pueden ver el video haciendo clic en "📎 Ver recurso"
  8. Pueden comentar sus opiniones sobre el tutorial
Resultado: Docente comparte contenido ↔ Estudiantes aprenden e interactúan

⚙️ Configuración y Mantenimiento

Cambiar contraseña docente (por administrador TI)

Edita el archivo js/admin.js, busca la sección "usuariosValidos" y modifica:

const usuariosValidos = { 'docente': 'nueva_password_aqui', 'admin@colegio.edu': 'otra_password_aqui' };

Cambiar colores del portal

Edita css/estilos.css, busca "#2d6a4f" y reemplaza con tu color.

Limpiar todos los datos

En la consola del navegador (F12), ejecuta:

localStorage.clear(); location.reload();

Pre-cargar datos de demostración

Abre datos-demo.js en la consola (F12) para cargar ejemplos.

🔧 Resolución de Problemas Comunes

❓ "No veo el contenido que cargué"

✅ Solución:

  • Recarga la página (F5)
  • Verifica estar en la sección correcta
  • Intenta en otro navegador

❓ "Veo datos de otro usuario"

✅ Solución:

  • Estás en otro navegador (cada uno tiene sus datos)
  • Abre en el MISMO navegador que el usuario original

❓ "Todos los comentarios desaparecieron"

✅ Solución:

  • Se borraron al limpiar caché
  • No se puede recuperar (sin servidor)
  • Prevención: Hacer backups periódicos (copiar contenido)

❓ "Quiero cambiar algo del diseño"

✅ Solución:

  • Edita archivos HTML y CSS
  • Recarga el navegador para ver cambios
  • No hay compilación necesaria

💡 Recomendaciones para el Colegio

  1. Capacitación: Entrenar docentes en 1-2 horas
  2. Acceso: Dejar el archivo en servidor de la institución
  3. Backup: Hacer copias de seguridad cada mes
  4. Monitoreo: Revisar comentarios regularmente
  5. Futuro: Considerar backend real para datos persistentes
  6. Documentación: Guardar este archivo de instrucciones
